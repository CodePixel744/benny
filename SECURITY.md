# Security Policy

## Reporting a vulnerability

Your help keeping the community safe is appreciated. Please **do not** open a
public issue for unreleased security vulnerabilities.

Instead, report privately by emailing the maintainers (see the repository
owner profile for contact details) or opening a
[GitHub Security Advisory](https://github.com/benny/benny/security/advisories/new).

You can expect an acknowledgement within 72 hours and a plan for the fix
within 5 business days.

## Supported versions

Only the latest release on the `main` branch receives security fixes.

## Disclosure

We will coordinate a reasonable disclosure timeline so that users have time to
update before the details are made public.
